# 星宇股份（601799）财报数据首位 / 末位数字分布检验

- **数据来源**：巨潮资讯网（cninfo，证监会指定信息披露平台）官方定期报告 PDF
- **覆盖报告**：13 期（2015年报, 2016年报, 2017年报, 2018年报, 2019年报, 2020年报, 2021年报, 2022年报, 2023年报, 2024年报, 2025年报, 2026H1, 2026Q1）
- **报表范围**：各期合并资产负债表、合并利润表、合并现金流量表
- **解析数据行**：1404 行；主口径样本 n = 1400

## 一、首位数字：总体结论

主口径（A）样本 n = 1400：

- 卡方检验：χ² = 7.33（df = 8），p = 0.502
- MAD = 0.0069，Nigrini 判定「可接受 (acceptable conformity)」
- 蒙特卡洛 MAD 检验（20000 次）：p = 0.331
- KS 型统计量 D = 0.0139（5% 临界值 0.0363）
- 最大 |z| = 1.87

**结论：星宇股份财报金额的首位数字分布符合 Benford 对数分布。**

## 三、末位数字：0-9 均匀性检验

自然数据（如金额）的**末位数字**应近似在 0-9 上均匀分布，各占 10%。
末位数字检验只对「末位不受人为约束」的数有效，因此剔除**明显取整**的金额：
报告形态下有 ≥2 个连续尾零的数（如 `100,000,000.00`、`500,000`、`23,000`）——它们的末位是被舍入固定死的。

- 候选金额：1400 个
- 剔除明显取整：91 个（6.5%）
- 有效样本：**n = 1309**
- 卡方检验：χ² = 15.84（df = 9），p = 0.0704
- MAD = 0.0085（无固定阈值，用蒙特卡洛判定）
- 蒙特卡洛 MAD 检验（20000 次）：p = 0.1337
- 最大 |z| = 2.85

**结论：末位数字不拒绝 0-9 均匀分布。**

## 五、数据质量校验

- 会计恒等式（资产总计 = 负债合计 + 所有者权益合计）：**13/13 期通过**
- 跨报告期衔接（本年上期数 = 上年本期数）：**902/933 项一致**

## 六、局限

1. 卡方检验假设样本独立，而同一报表内科目存在勾稽关系，p 值仅供参考。
2. 分表/分时段子样本量小，检验敏感度不同，可能出现轻度偏离。
3. 末位数字检验已剔除明显取整的金额；若剔除后样本量过小，结论稳定性下降。
4. Benford / 末位数字检验只能说明数字分布是否自然，不能单独证明或排除财务舞弊。
